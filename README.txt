BILAL EZZINE — PORTFOLIO PROFESSIONNEL 2026
==========================================
OUVRIR LE SITE : extraire l'archive ZIP, puis ouvrir index.html dans un navigateur.

PAGES
- index.html : Accueil
- experience.html : Expérience professionnelle
- projects.html : Projets
- skills.html : Compétences
- education.html : Formation
- contact.html : Contact et téléchargement du CV

FONCTIONNALITÉS : français par défaut avec bouton FR/EN, mode clair/sombre, navigation mobile, animations discrètes (désactivées si l'utilisateur réduit les animations), balises SEO et données structurées.

PUBLICATION SUR GITHUB PAGES : déposer tous les fichiers à la racine du dépôt, puis activer GitHub Pages (Settings > Pages > Deploy from a branch).

À VÉRIFIER AVANT PUBLICATION
- Les dates et intitulés de poste (notamment « Stagiaire Assistant Manager de Production », juin 2026 — aujourd'hui).
- Le numéro de téléphone, visible publiquement sur la page Contact.
- Les CV PDF/Word, à aligner avec le contenu du site.
- L'interface du projet EasyHire est une illustration, pas une capture d'écran.
